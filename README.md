# VetStudy

Aplicação de estudos de anatomia veterinária.

## Estrutura esperada

- `index.html` — página principal da aplicação.
- `assets/` — imagens utilizadas nas questões visuais.
- `LEIA-ME.txt` — notas da versão e limitações conhecidas.

## Publicação do pacote atual

O pacote atualizado está disponível como arquivo ZIP nesta conversa. Para publicar pelo navegador, extraia o ZIP no computador e envie os arquivos extraídos para a raiz deste repositório, mantendo a pasta `assets/` e seus nomes. Depois, faça commit na branch `main`.

## Limitações conhecidas da versão atual

- Não há backend nem sincronização: os dados são salvos no `localStorage` do navegador/dispositivo.
- A criação automática de questões para materiais enviados é preliminar e requer revisão pedagógica.
- O resumo ainda não é uma síntese didática completa validada; a versão preserva o texto extraído e um resumo preliminar.
- A versão não passou por uma bateria de testes em navegador nesta entrega.
